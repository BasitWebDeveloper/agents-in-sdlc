Explora GitHub Copilot durante todo el ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y un backlog compartido. Planificarás cambios, crearás código, probarás el comportamiento, revisarás solicitudes de incorporación de cambios y gestionarás el trabajo con agentes mediante un proceso iterativo.

## Escenario

Eres desarrollador de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con una temática de desarrollo. El backlog del equipo ya está registrado como incidencias de GitHub e incluye funcionalidades como el filtrado y la paginación, además de mejoras de calidad relacionadas con la accesibilidad y los estándares de código.

## Elegir el entorno

GitHub Copilot está disponible en los entornos en los que trabajas. Elige el que mejor se adapte a tu forma de desarrollar. Cada taller tiene su propia configuración y utiliza el mismo escenario de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes desde el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia entre modos de sesión, colabora en lienzos y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
